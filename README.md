# Temirlan Mongush Portfolio

This repository now contains a GitHub Pages-friendly portfolio site for Temirlan Mongush.

## Focus

- Software engineering student profile
- Leadership, awards, volunteering, and education
- Lightweight static site built with Vite
- Relative asset paths for easier GitHub Pages deployment

## Local development

```powershell
npm install
npm run dev
```

## Production build

```powershell
npm run build
```

The build output is generated into `docs/` for GitHub Pages hosting.
